# Rules for this repository

**Every release has a changelog.** Before tagging, add a section for the version to `CHANGELOG.md`, listing the new, changed or removed capabilities. Each change is one line, starting `New:`, `Changed:` or `Removed:`, and describes the capability briefly and directly. The Release workflow publishes that section as the release notes, and stops if the section is missing.

**REFERENCE.md is the API's documentation.** The app's Wiki keeps one short Obsidian API page, which links here. The part of `REFERENCE.md` above its marker line is the guide, written by hand: update it when a change alters how a part of the API works. The part below is generated by `python tools/reference.py` from the source and the comment above each call, so write those comments for mod authors. Run it before every release; the Release workflow runs `--check` and stops when the file is stale.
